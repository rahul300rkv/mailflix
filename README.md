## 🚀 Overview

**MailFix** is a zero-signup, 100% free web platform engineered specifically for **Indian salaried employees, job switchers, freelancers, and small business owners**. It combines AI-powered workplace communication utilities (converting Hinglish drafts to corporate emails and WhatsApp messages) with high-precision Indian financial calculators calibrated for **Union Budget 2025–26 tax slabs**.

All calculations run entirely client-side in the browser, guaranteeing zero telemetry and complete privacy for sensitive salary details.

## 🔒 Privacy & Security

- **Zero-Storage Architecture**: Calculations for salary, rent, and investments are executed entirely on your local browser.
- **No Sign-Up Required**: No emails, passwords, phone numbers, or credit card information collected.
- **Client-Side Image Processing**: Photo and signature resizing occurs in-memory via HTML5 Canvas; images never touch an external server.

---

## 🏗️ Architecture & Tech Stack

- **Frontend**: Clean semantic HTML5, Modern CSS / Tailwind CSS, Plus Jakarta Sans typography, Neo-Brutalist design language.
- **Dynamic Application**: React 18, TypeScript, Lucide Icons, Vite.
- **Deployment**: Hosted on [Netlify](https://www.netlify.com/) with automated Edge CDN caching, clean URL redirects (`_redirects`), and zero-cache sitemap/robots directives (`netlify.toml`).
- **SEO & Discoverability**: Schema.org JSON-LD structured data (`WebApplication`, `ItemList`, `FAQPage`, `BreadcrumbList`), OpenGraph & Twitter Cards, geo-targeting meta tags (`geo.region: IN`), and automated XML/HTML/RSS sitemaps.

## 💻 Local Development

Clone the repository and start the development server:

```bash
git clone https://github.com/rahul300rkv/mailflix.git
cd mailflix
npm install
npm run dev
```

Open `http://localhost:3000` in your web browser.
